# Repository status

This repository contains the complete Clock Advanced source tree:

- Home Assistant integration and schema migration
- canonical Card and compatibility loader
- bilingual EN/DE setup, options, entities and Card
- generic HA action phases and versioned event contract
- privacy-aware diagnostics
- schedule, package and Card runtime tests
- disposable Docker development lab with read-only source mounts
- HACS metadata and deterministic release builder

The manifest is the only active version source. Unreleased work is recorded under `CHANGELOG.md → Unreleased`.
